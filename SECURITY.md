---

## Reporting a Vulnerability

If you discover a security vulnerability or critical flaw (including soundness violations in game-semantic compilation, cryptographic bypasses in proof attestation, or RPC execution vulnerabilities), please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories:
   [https://github.com/tryggth/bourbakimesh/security/advisories/new](https://github.com/tryggth/bourbakimesh/security/advisories/new)
3. Provide detailed reproduction steps, impacted components, and proof-of-concept payloads.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible public disclosure and patch.
